# Notes for Claude

- `docs/owner/rulings.md` holds the owner's binding design rulings. Read it before changing how agents, the runtime, or the tree work.
- `docs/owner/prompts.md` is every prompt the owner has sent, verbatim. A Stop hook in `~/.claude/settings.json` runs `scripts/owner-prompts-hook.sh` after each turn: it rebuilds the file from the session transcript and commits and pushes only that file. The hook lives in the container, so re-add it if it is missing.
- `.claude/workflows/prompt-redteam.js` is the owner's red team: a swarm of six teams of three, one area of the code each; every agent reads `prompts.md`, hunts drift, and each team confirms findings and fixes by 2-of-3 quorum. Run it on a frozen worktree of the commit under audit (Workflow with this `scriptPath`, `args: {round: N, repo: <that worktree>}`); fixers work in their own worktrees, one per area, and merge one at a time with the full suite after each, fix every confirmed finding, record each in `docs/owner/drift.md` as "fixed, awaiting recheck" with its commit, and run it again until a round confirms nothing new and closes every fix.
- `docs/owner/redteam-findings.md` keeps every red-team finding, vote and recheck, round by round. After each round run `node scripts/redteam-findings.mjs <the run's journal.jsonl> <round>` and commit it.
- Red-team agents and fix agents run on Opus at medium effort (owner, 2026-10-17: "why don't you use opus medium to speed up the work").
